# Rebanta Daadhiich — Portfolio

This is my personal cybersecurity portfolio website built to showcase my background, technical skills, projects, education, and contact information. The site is deployed using GitHub Pages.

## Live Site

https://Rebantaa.github.io

## Tech Stack

- HTML
- CSS
- JavaScript
- GitHub Pages

## Features

- Responsive portfolio landing page
- Interactive section navigation
- Random facts search feature
- Project cards with concepts and technologies
- Experience timeline
- Education section
- Resume and contact links

```bash

cd Rebantaa.github.io
```
